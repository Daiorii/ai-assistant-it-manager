# AI Assistant for IT Managers

Desktop AI Assistant for IT Managers using Python and Gemini API.

---

# Project Goal

The goal of this project is to develop a desktop AI assistant for IT managers that can process user requests, generate AI responses, and provide a modern interactive interface.

---

# Technologies Used

- Python 3.13
- CustomTkinter
- Google Gemini API
- python-dotenv

---

# Installation Guide

## 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

---

## 2. Install Required Libraries

Open terminal and run:

```bash
pip install customtkinter
pip install google-generativeai
pip install python-dotenv
```

---

# Run Instructions

## 1. Get Gemini API Key

Open:

https://aistudio.google.com/app/apikey

Create your API key.

---

## 2. Create `.env` File

Create a file named:

```env
.env
```

Add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

---

## 3. Start Application

Run:

```bash
python main.py
```
